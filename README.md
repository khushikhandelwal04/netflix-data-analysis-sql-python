# 🎬 Netflix Data Analysis Using Python & SQL

## 📌 Project Overview

This project analyzes the Netflix dataset using Python and SQL Server.

The project includes:
- data cleaning
- normalization
- exploratory data analysis (EDA)
- visualization
- SQL querying
- insights generation

- Pandas

- SQLAlchemy
- Jupyter Notebook
